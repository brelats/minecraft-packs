# minecraft-packs

Resource packs of my Minecraft plugins. Servers running the plugins send players a link to these files
through [jsDelivr](https://www.jsdelivr.com), so server owners don't have to host the pack or open a port.

Each plugin has its own folder, and each release of a plugin is a tag (`thesift-1.2.1`):

```
https://cdn.jsdelivr.net/gh/brelats/minecraft-packs@<tag>/<plugin>/<pack>.zip
```

The files are generated by the plugins themselves (one per Minecraft version and setting that changes
the pack). Don't edit them by hand: the plugins check each pack's contents before using it.
